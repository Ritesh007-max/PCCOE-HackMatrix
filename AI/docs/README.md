# AI Documentation

In-depth technical documentation, design specifications, data dictionaries, and experiment reports for the PolicySetu AI subsystem.

---

## Sections

- `architecture/`: High-level system architecture, ingestion pipelines, vector indexing flow, and rule engine integration patterns.
- `datasets/`: Dataset curation methodologies, data dictionaries, annotation guidelines, and licensing notes.
- `policy-model/`: Domain modeling for government policies, eligibility logic taxonomy, condition trees, and rule specification grammar.
- `api/`: API interface definitions, endpoint schemas, request/response examples, and error codes for the FastAPI service.
- `experiments/`: Experiment tracking records, model selection rationales, embedding benchmark results, and ablation studies.
